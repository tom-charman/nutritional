# PostgreSQL Database Setup

This directory contains all files needed to set up the PostgreSQL database for the nutritional tracker application.

## Server Requirements

- **OS**: Debian 12 (Bookworm)
- **RAM**: 1GB minimum (optimized for Google Cloud E2-micro)
- **PostgreSQL**: Version 15+

## Quick Start (Debian 12 Server)

### 1. Install PostgreSQL

```bash
# Update package lists
sudo apt update

# Install PostgreSQL 15
sudo apt install -y postgresql-15 postgresql-contrib-15

# Verify installation
sudo systemctl status postgresql
```

### 2. Run Setup Script

```bash
cd database
chmod +x setup.sh
sudo ./setup.sh
```

This script will:
- Create the database and user
- Apply optimized configuration for 1GB RAM
- Initialize the schema
- Restart PostgreSQL

### 3. Configure Application

Create `.env` file in the project root:

```bash
cd ..
cp .env.example .env
```

Edit `.env` and set:
```
DATABASE_URL=postgresql://nutritional_user:your_secure_password@localhost:5432/nutritional_db
```

### 4. Test Connection

```bash
# Activate Python environment
source .venv/bin/activate  # or use uv

# Test connection
python -c "from nutritional.database.connection import test_connection; print('✓ Connected' if test_connection() else '✗ Failed')"
```

## Manual Setup Steps

If you prefer to set up manually:

### Create Database and User

```bash
sudo -u postgres psql -f create_db.sql
```

**Note**: The script will prompt you to enter a secure password. Generate one with:
```bash
openssl rand -base64 32
```

### Apply Schema

```bash
sudo -u postgres psql -d nutritional_db -f init.sql
```

### Apply Optimized Configuration

```bash
# Backup original config
sudo cp /etc/postgresql/15/main/postgresql.conf /etc/postgresql/15/main/postgresql.conf.backup

# Apply optimizations
sudo cp postgresql.conf.template /etc/postgresql/15/main/postgresql.conf.d/nutritional.conf

# Apply local-only security
sudo cp pg_hba.conf.local /etc/postgresql/15/main/pg_hba.conf

# Ensure localhost-only listening
sudo sed -i "s/^listen_addresses.*/listen_addresses = 'localhost'/" /etc/postgresql/15/main/postgresql.conf

# Restart PostgreSQL
sudo systemctl restart postgresql
```

## Configuration Details

### Memory Settings (1GB RAM Server)

| Setting | Value | Purpose |
|---------|-------|---------|
| `shared_buffers` | 128MB | Primary cache sized for 1GB RAM |
| `work_mem` | 4MB | Prevents complex sorts from consuming all RAM |
| `maintenance_work_mem` | 32MB | Keeps background tasks lean |
| `max_connections` | 20 | Reduces per-connection memory overhead |
| `effective_cache_size` | 512MB | Query planner hint for OS cache |

### Security Settings

- **Password**: Secure random password (generated by setup.sh)
- **Authentication**: SCRAM-SHA-256 (most secure method)
- **Network**: Localhost only (127.0.0.1, ::1)
- **Remote Access**: BLOCKED (all external connections rejected)
- **Application**: Must run on same server as database

**Security Architecture:**
1. PostgreSQL only listens on localhost
2. pg_hba.conf explicitly rejects external connections
3. Application connects via localhost (no network exposure)
4. Remote admin only via SSH tunnel

To enable remote administration via SSH tunnel:
```bash
# From your local machine
ssh -L 5432:localhost:5432 user@server

# Then connect to localhost:5432
psql -h localhost -U nutritional_user -d nutritional_db
```

## Monitoring

### Check Database Size
```bash
sudo -u postgres psql -d nutritional_db -c "SELECT pg_size_pretty(pg_database_size('nutritional_db'));"
```

### Check Active Connections
```bash
sudo -u postgres psql -d nutritional_db -c "SELECT count(*) FROM pg_stat_activity WHERE datname = 'nutritional_db';"
```

### Check Memory Usage
```bash
# PostgreSQL process memory
ps aux | grep postgres | awk '{sum+=$6} END {print "Total: " sum/1024 " MB"}'
```

## Backup and Restore

### Backup
```bash
# Full database backup
sudo -u postgres pg_dump nutritional_db > backup_$(date +%Y%m%d).sql

# Compressed backup
sudo -u postgres pg_dump nutritional_db | gzip > backup_$(date +%Y%m%d).sql.gz
```

### Restore
```bash
# From plain SQL
sudo -u postgres psql nutritional_db < backup_20250101.sql

# From compressed
gunzip -c backup_20250101.sql.gz | sudo -u postgres psql nutritional_db
```

## Troubleshooting

### Connection Refused
```bash
# Check if PostgreSQL is running
sudo systemctl status postgresql

# Check if it's listening
sudo netstat -tlnp | grep 5432
```

### Authentication Failed
```bash
# Verify user exists
sudo -u postgres psql -c "\du"

# Reset password
sudo -u postgres psql -c "ALTER USER nutritional_user WITH PASSWORD 'new_password';"
```

### Out of Memory
```bash
# Check PostgreSQL logs
sudo tail -f /var/log/postgresql/postgresql-15-main.log

# Reduce max_connections or work_mem if needed
```

## Local Development (Docker)

For local development on Windows/Mac, use Docker Compose from the project root:

```bash
docker-compose up -d
```

This provides a PostgreSQL instance without system installation.
